# 🚀 Vinay Yadav - Personal Portfolio

A sleek, modern, and high-performance developer portfolio built with pure HTML5, CSS3, and JavaScript[cite: 1, 2, 3]. It features a dark glassmorphism theme, smooth animations, interactive UI elements, and a fully functional dynamic contact form powered by Formspree[cite: 1, 2, 3].

---

## ✨ Key Features

* **Dark Glassmorphism Theme:** Designed with dynamic floating glow background orbs and sleek glass effects[cite: 2].
* **Interactive Navigation:** Includes hover popup tooltips for desktop navigation and a responsive mobile menu toggle drawer[cite: 1, 2].
* **Scroll Reveal Animations:** Powered by JavaScript's `IntersectionObserver` API for fast and smooth section animations[cite: 1].
* **Functional Contact Form:** AJAX-based form submission connected to Formspree with client-side error handling and custom toast notifications[cite: 1, 3].
* **Fully Responsive:** Optimized across desktop, tablet, and mobile displays[cite: 2].

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Modern Variables & Flexbox/Grid), JavaScript (ES6+)[cite: 1, 2, 3]
* **Fonts & Icons:** Plus Jakarta Sans (Google Fonts), FontAwesome 6.4.0
* **Form Handler:** Formspree API (AJAX)[cite: 1]
